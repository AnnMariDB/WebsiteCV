Projects / Machine Learning Project 1

Machine Learning Project 1

Predicts a learner's grade class from study time, absences, parental support, activities and GPA. Four models were trained and compared, and a web dashboard shows how each performed and predicts a grade for a new learner.

Type
University project
Year
2025
Context
Group project, Belgium Campus
Tech
  • Python
  • scikit-learn
  • XGBoost
  • TensorFlow (Keras)
  • Dash
  • Plotly
Outcome
A random forest did best, with about 91% accuracy on held-out validation data, ahead of XGBoost (about 90%), logistic regression (about 83%) and a neural network (about 81%).

The student data was cleaned and prepared, then split 80/20 with the same mix of grade classes in both parts. Accuracy, precision, recall and F1 were compared for logistic regression, a random forest, XGBoost and a small neural network.

A Dash web app, set up to run on Render, charts the results for each model and lets a user enter a learner's details to get a predicted grade from the random forest.
